# Introduction
RockboxReplugged is a project that aims to overhaul and completely rewrite some of the core rockbox plugins

I was inspired to start this project because of a shocking lack of quality in some of rockbox's most important plugins whether that poor quality be the worst and most jarring search menu ive ever seen or a video player lacking basic codecs this projects main focus is to bring some of these core plugins out of the early 2010's and give them a much needed rework

## Roadmap
- [ ] Complete Search plugin rewrite
- [ ] Introduce MKV or MP4 video file support
- [ ] Make my music library generally easier to scrobble
- [ ] Address performance issues in many useful plugins like Pictureflow
